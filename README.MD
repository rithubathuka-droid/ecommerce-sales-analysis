# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data to understand revenue performance, product sales, customer behavior, country-wise sales, monthly trends, and cancellations.

The project uses **Excel, SQL, and Power BI** to clean, analyze, and visualize the data.

## Project Objective

The main objectives of this project are:

* Analyze overall sales and revenue
* Identify top-performing products
* Identify top-performing countries
* Analyze monthly revenue trends
* Identify high-value customers
* Analyze cancellations and returns
* Calculate important sales metrics
* Create an interactive Power BI dashboard
* Generate useful business insights

## Dataset

The project uses the **Online Retail** e-commerce dataset containing transactional sales information such as:

* Invoice Number
* Stock Code
* Product Description
* Quantity
* Invoice Date
* Unit Price
* Customer ID
* Country

## Tools & Technologies

* **Excel** – Data cleaning and initial analysis
* **SQL** – Data cleaning, transformation, and analysis
* **Power BI** – Interactive dashboard and data visualization

## Key Analysis

The project analyzes:

* Total Revenue
* Monthly Revenue
* Top 10 Products
* Top 10 Countries
* Customer Revenue
* Unique Orders
* Average Order Value
* Cancellations and Returns
* Sales Trends

## Key Insights

* Net revenue was approximately **9.73 million** after considering negative transactions.
* **November 2011** recorded the highest monthly revenue at approximately **1.50 million**.
* The **United Kingdom** was the highest-revenue country.
* **DOTCOM POSTAGE** was among the highest-revenue products.
* High-value customers contributed significantly to overall revenue.
* Cancellations and returns had a noticeable impact on revenue.

## Project Files

* Sales_Analysis.sql – SQL queries and analysis
* online retail.pbix – Power BI dashboard
* Ecommerce_Sales_Analysis.pptx – Project presentation

## Dashboard

The Power BI dashboard provides an interactive view of sales performance, including revenue trends, products, countries, customers, and cancellations.

## Conclusion

This project demonstrates how Excel, SQL, and Power BI can be combined to transform raw e-commerce data into meaningful business insights and support data-driven decision-making.
